# Проверка wk

Воспроизводимый протокол для CLI. Исторические прогоны backend и прежние задачи
сохраняются в истории Git; их результаты не считаются проверкой текущего CLI.

## Команды

Из корня wk:

```sh
nix develop -c just lint
nix develop -c just test
nix develop -c env CGO_ENABLED=1 go test -race ./...
nix flake check --print-build-logs
```

`just lint` проверяет gofmt и go vet. `just test` требует **100% покрытия каждой
Go-функции**, включая main. Порог не понижен; отчёты coverage.out и
coverage-summary.txt генерируются локально и не версионируются.
Nix собирает статический бинарь и повторяет lint и тесты.

## Что закреплено тестами

| Область | Проверяемое поведение |
|---|---|
| Команды и HTTP | JSON, коды выхода, отсутствие токена в выводе/файлах, порядок запросов proposals |
| Документация | Семь golden-сценариев против Python checker: stdout, код выхода, реестр |
| Политики | Экспорт совпадает с серверным export_block; параметры compile едины для init/sync/check |
| Офлайн | Отчёт docs сохраняется; ошибки docs дают 1, отсутствие сети при чистых docs — 3 |
| Пути | Симлинк над корнем и новый корень init работают; симлинки внутри, traversal и .git запрещены |
| Хуки | Все четыре команды, stdin, лишние поля, битый JSON, отсутствие манифеста, блокировки с кодом 2 |
| Stop | Активное продолжение не обращается к серверу; офлайн пропускается; stderr содержит одну строку |
| SessionStart | Ровно один JSON дополнительного контекста при устаревании; иначе пустой stdout |
| Раскладка | Offline init устанавливает конфиги и две копии каждого навыка; повторный init доставляет пропущенное |
| Существующие файлы | Конфиги и валидные навыки сохраняются даже с force, различия доступны как diff |
| Навыки | Шесть проверок формата/содержимого встроены в init и doctor |
| Хранилище | Отказы диска, прерванная запись, сохранение манифеста последним, digest и кэш шаблонов |
| Карантин шаблонов | 422/E_TEMPLATE_INVALID отличается от 404/E_TEMPLATE_UNKNOWN; init не меняет проект и не использует валидный кеш при отказе сервера |
| Ошибки API | Выводятся HTTP-статус и безопасный код из ограниченного по размеру ответа, без message/details |

Локальный тест также сверяет встроенные навыки и конфиги с соседними `skills/`
и `hooks/install/`. При сборке wk как отдельного репозитория этих соседей нет;
валидируются встроенные копии, сеть для их доставки не нужна.

Платформа: x86_64-linux, Go 1.26.7 из flake.lock. `just lint`, `just test`
и Nix-сборка проходят; итог покрытия:

```text
total:                                              (statements)            100.0%

```

Симлинки над корнем проверены регрессионными тестами на Linux. Сборки
aarch64-linux, x86_64-darwin и aarch64-darwin на этом хосте не запускались.
Проверки запускают настоящий Git и локальный httptest.Server; подключение
к рабочей вике не требуется.
