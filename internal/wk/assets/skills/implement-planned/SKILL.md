# Реализация запланированных фактов

1. Выполни `wk policy sync`.
2. Прочитай `docs/INDEX.md`, `docs/system/overview.md`, `docs/system/domain.md`.
3. Прочитай `docs/components/<компонент>/component.md` и файлы по ссылкам из него.
4. Отбери факты со статусом `planned`. Факты в статусе `draft` не реализуются.
5. Для каждой ссылки `rule-…` в отобранных фактах выполни `wk policy show <rule-id>`. Код пиши по правилу.
6. Факт противоречит правилу уровня MUST или другому факту — код по этому факту не пиши, заведи `Q-…` в `docs/open-questions.md`.
7. Напиши код. Поставь маркер `doc: <ID>` в каноническом месте по таблице в `docs/_meta/workflow.md`.
8. Переведи статус реализованного факта в `implemented`. Остальное содержимое факта не меняй.
9. Если для работы нужен факт, которого нет в документации, или факт нужно изменить — остановись, вызови скилл `doc-card`, в код молча не добавляй.
10. Выполни `wk check --strict`.
