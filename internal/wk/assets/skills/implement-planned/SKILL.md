# Реализация запланированных фактов

1. Выполни `wk policy sync`.
2. Прочитай `docs/INDEX.md`, `docs/system/overview.md`, `docs/system/domain.md`.
3. Прочитай `docs/components/<компонент>/component.md` и файлы по ссылкам из него.
4. Отбери факты со статусом `planned`. Факты в статусе `draft` не реализуются.
5. Напиши код. Поставь маркер `doc: <ID>` в каноническом месте по таблице в `docs/_meta/workflow.md`.
6. Переведи статус реализованного факта в `implemented`.
7. Если для работы нужен факт, которого нет в документации — остановись, вызови скилл `doc-card`, в код молча не добавляй.
8. Выполни `wk check --strict`.
