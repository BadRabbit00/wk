# Карточка факта в документации

1. Определи тип факта и префикс ID по `docs/_meta/ids.md`. Новых префиксов не придумывай.
2. Определи файл по таблице в `ids.md`. ID определяется ровно в одном месте.
3. Выполни `wk policy search "<суть факта>"`. Найденные правила из блока политик в `AGENTS.md` прочитай командой `wk policy show <rule-id>`. Правила вне блока не используй.
4. Создай карточку или строку таблицы по `docs/_meta/format.md`. Статус — `draft`. Изменение существующего факта — по разделу 4 `docs/_meta/workflow.md`.
5. Сошлись на применимые политики по ID `rule-…`. Текст правила не пересказывай.
6. Факт противоречит правилу уровня MUST — факт не записывай, заведи `Q-…` в `docs/open-questions.md` со ссылкой на правило.
7. Если значение поля неизвестно — заведи `Q-…` в `docs/open-questions.md` и сошлись на него из карточки. Догадку в карточку не пиши.
8. Статус `draft` → `planned` переводит человек. Сам не переводи.
9. Выполни `wk check --strict`.
