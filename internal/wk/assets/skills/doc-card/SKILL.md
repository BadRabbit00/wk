# Карточка факта в документации

1. Определи тип факта и префикс ID по `docs/_meta/ids.md`. Новых префиксов не придумывай.
2. Определи файл по таблице в `ids.md`. ID определяется ровно в одном месте.
3. Создай карточку или строку таблицы по `docs/_meta/format.md`. Статус — `draft`.
4. Если значение поля неизвестно — заведи `Q-…` в `docs/open-questions.md` и сошлись на него из карточки. Догадку в карточку не пиши.
5. Статус `draft` → `planned` переводит человек. Сам не переводи.
6. Выполни `wk check --strict`.
