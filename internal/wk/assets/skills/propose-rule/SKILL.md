# Предложение правила в вику

1. Убедись, что правила нет: `wk policy search "<суть>"`.
2. Напиши файл правила с разделами «Правило», «Обоснование», «Примеры». Поля `category`, `level`, `applies_to`, `origin` обязательны.
3. Выполни `wk propose --file <path>`.
4. Напечатай `pid` и ссылку. Решение принимает человек в UI.
5. Принятия не жди, статус в цикле не опрашивай. Продолжай работу по текущим политикам.
6. Выполни `wk check --strict`.
