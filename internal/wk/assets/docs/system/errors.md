# Ошибки

## Формат ошибки

<Единый формат ответа с ошибкой для всех API, например:>

```json
{ "error": { "code": "ERR-<…>", "message": "…", "details": {} } }
```

<Код в ответе = ID ошибки без изменений. Тогда клиент, лог и документация говорят на одном языке.>

## Каталог
