# Внешние зависимости всех компонентов

> Одна таблица на все языки — агенту не нужно открывать `pyproject.toml`, `package.json`,
> `go.mod` и `Cargo.toml` по отдельности. Только **прямые** зависимости, не транзитивные.
> Имя ID: `DEP-<экосистема>-<пакет>`: `py`, `npm`, `go`, `rs`, `nix`, `sys` (системные библиотеки).
> Версия — как ограничение в манифесте; точная — в lock-файле.

| id | пакет | версия | компоненты | зачем | почему не другое | status |
|---|---|---|---|---|---|---|
| DEP-<py-fastapi> | `<fastapi>` | `<^0.115>` | SVC-<…> | <HTTP-фреймворк> | <ADR-… / одна строка> | <…> |

## Правила

- Новая зависимость появляется здесь со статусом `draft` **до** того, как её добавят в манифест.
- Две библиотеки для одной задачи в одном компоненте — только с объяснением в «почему не другое».
- Лицензии, несовместимые с проектом: <список, например AGPL>.
